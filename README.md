# CCNA Packet Tracer Labs (Jeremy’s IT Lab)

This repository contains Cisco Packet Tracer lab files completed while following the **Free CCNA 200-301 course by Jeremy’s IT Lab**.  
I use this repo to track my daily practice and reinforce key networking concepts.

> Note: The course videos, original lab designs, and all educational content belong to **Jeremy’s IT Lab**.  
> This repo only stores **my own lab work and notes** based on that course.

---

## What’s inside

- `.pkt` files organized by **Day / Topic** (for example: `Day19-VLANs.pkt`, `Day26-OSPF-Part1.pkt`)
- Occasional text notes (`.md` or `.txt`) explaining:
  - Commands used
  - Verification steps (`show ip route`, `show spanning-tree`, etc.)
  - Common mistakes I hit and how I fixed them
